┌─ TROUBLESHOOTING ─────────────────────────────────────────────────────────┐
│                                                                             │
│  "Button doesn't show"                                                     │
│    → App might be already installed                                       │
│    → Try different browser                                                │
│    → Check browser console (F12) for errors                              │
│                                                                             │
│  "Banner won't appear"                                                     │
│    → Scroll down the page to trigger it                                   │
│    → Wait 8 seconds for auto-trigger                                      │
│    → Refresh page if previously dismissed                                 │
│                                                                             │
│  "Modal shows wrong instructions"                                          │
│    → Check your device type (iOS/Android/Desktop)                        │
│    → Try different browser                                                │
│    → Check user agent in DevTools                                         │
│                                                                             │
│  "Installation fails"                                                      │
│    → Ensure HTTPS connection (not HTTP)                                   │
│    → Try different browser                                                │
│    → Clear cache and try again                                            │
│                                                                             │
│  "Store links broken"                                                      │
│    → Native apps aren't published yet (expected)                         │
│    → Links will work once apps are on stores                             │
│    → PWA installation works without native apps                          │
